- Externalize static inline styles; retain runtime geometry/data bindings. Use logical properties/start-end alignment; explicitly check directional icons/transforms/drawers/floating panels/calendar geometry. Browsers do not reverse everything automatically.
- Shell owns gutters; PageContainer owns standard/wide/form widths. Avoid duplicate padding/max-width; let flex/grid children shrink and verify narrow tables/navigation/wrapping. Semantic theme tokens must be noncyclic; media breakpoints literal; preserve light/dark Arabic readability.
- Use focused source/reference checks and isolated probes; exclude migrations, suites, `dist/`, dependencies and runtime data. Do not modify generated assets. `pnpm lint`/`format` write files. CSS moves require import/link/scoped-reference/rule/cascade checks.
- When authorized/available, verify mobile/tablet/desktop, RTL/LTR, themes, overflow and keyboard focus. Parsing does not verify interactions/layout/Arabic/PDF; report limits. Never expose patient content, commit `.env.local`, or put secrets in `VITE_*`.
