# Layout, RTL and shared UI by source area

All **15 design findings D1–D15**, **11 shell findings S1–S11** and three shell responsive risks have source corrections. This table merges original evidence with implemented behavior; completed findings are not new defects. Current browser evidence is limited to [the explicit matrix](../testing/guide.md); [open navigation findings](navigation.md) remain separate.

CSS ownership: [CSS guide](css.md). Static styling lives in external shared/scoped files; finite arrow/severity/swatch/signature colors use classes/tokens. Runtime floating bounds, progress/timing, avatar/column colors/counts, skeleton heights and calendar geometry remain bindings; textarea resizing/scroll locking use DOM values. Cosmetic random skeleton widths removed.

Evidence: source/template/CSS/import/theme audits and controlled overlay/shortcut/chart/floating probes passed; they did not render Vue/CSS. Later component/browser tests verify selected drawer/modal focus, charts/themes, panels, patient tabs/action clicks and print samples. Do not infer complete visual coverage from source completion.
