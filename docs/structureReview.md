# Frontend structure review

Reviewed and implemented **2026-11-07**. The original review covered 457 files under `src/` and `public/`. Findings were rechecked against current production source before implementation. The [current ledger](structureReviewFiles.md) records retained, moved, new and removed owners. [Remaining verification](workCurrent.md) · [Evidence](doneCurrent.md) · [UI ownership](ui.md).

The existing feature structure remains. The four contract defects were confirmed; targeted extractions, ownership moves and deletion of unconsumed implementations followed. Source completion does not certify browser behavior.

## Retained after consumer checks

Direct test imports justify retaining `MiniBarChart.vue`, `DropdownMenu.vue`, `TaskFormInline.vue`, `utils/asyncStore.js`, `utils/pagination.js` and `utils/queryBuilder.js`. `normalizeList` and the tested legacy risk/interval helpers also remain; live cursor consumers use the new normalizer. Removing these would require an intentional decision about those consumers. The unused useApi query branch, small adapters, and feature field/config definitions were retained where the review only suggested possible future simplification.

## Verification boundary

Performed: targeted production/reference tracing; 1,430 resolved local import/style/test paths; lint of 101 production files with zero errors and 46 remaining prop/accessibility warnings; parsing of 97 CSS files, declaration/ownership checks and isolated synthetic production probes for visit mappings/defaults, dates, cursor/catalog handling, status metadata, account-scoped columns, resource/URL disposal and route filters. The probe substitutes the transport boundary and uses memory-only synthetic data. Existing affected test imports/contracts and a visit-isolation regression were updated with permission; suites were not run.

Generated component declarations remain generator-owned and await an authorized regeneration workflow. No migration inspection/change, suite execution, build/compilation/packaging, dependency/version/lockfile change, server/browser launch, real API probe or clinic storage access was performed. Breadcrumb rendering, selector interactions, column/export UI agreement, import consent flows, layout/RTL/themes/focus, PDF/native viewers and printing still need permitted runtime verification.
